Xena Music은 PC에 저장된 음악을 앨범아트와 가사로 감상하는 Windows용 음악 플레이어입니다. 음악 파일은 원래 자리에서 읽고, 보관함에 넣을 때 복사하거나 옮기지 않습니다.

## 시작하기

1. [최신 릴리스](https://github.com/xena-music/xena-music-releases/releases/latest)에서 `Xena-Music-x.x.x-Setup.exe`를 내려받아 실행합니다.
2. 설치가 끝나면 **파일 열기**를 누르거나 음악 파일을 창에 끌어 놓습니다.
3. 곡을 고르고 **Now Playing**에서 앨범아트와 가사를 감상합니다.

처음 실행할 때 'Windows의 PC 보호' 창이 나오면 **추가 정보 → 실행**을 누르세요.

새 버전이 나오면 앱이 알려 주고, 그 자리에서 업데이트할 수 있습니다. 버전마다 바뀐 점은 [릴리스 페이지](https://github.com/xena-music/xena-music-releases/releases)에 있습니다.

## 백업

**설정 → 백업**에서 앱 데이터를 자동으로 백업하거나 `.xena` 파일로 내보내고 되살릴 수 있습니다. 보관함, 설정, 가사, 플레이리스트, 감상 기록과 그림이 함께 담깁니다.

앱 데이터 백업에는 음악 파일이 들어가지 않습니다. 보관함에서 곡을 지우거나 플레이리스트를 삭제해도 음악 파일은 그대로 남습니다.

## 기본 단축키

| 단축키 | 기능 |
| --- | --- |
| `Space` | 재생 / 일시 정지 |
| `←` / `→` | 5초 뒤로 / 앞으로 |
| `Ctrl` + `←` / `→` | 이전 곡 / 다음 곡 |
| `Ctrl` + `O` | 음악 파일 열기 |
| `Ctrl` + `F` | 보관함 검색 |
| `Ctrl` + `M` | 미니 플레이어 |
| `Ctrl` + `Shift` + `L` | 데스크톱 가사 |
| `F1` | 도움말 |

전체 단축키는 앱의 도움말에서 볼 수 있고, 설정에서 바꿀 수 있습니다.

## 개인정보

음악 파일과 보관함은 내 PC에만 있습니다. 온라인 가사·앨범아트 검색 때는 검색어만 보내고 음악 파일은 보내지 않습니다. AI 자동 싱크도 PC 안에서 분석합니다. 분석에 쓰는 도구는 처음 쓸 때 내려받습니다.

자세한 내용은 [개인정보처리방침](https://xena-music.github.io/xena-music-releases/privacy.html)에 있습니다.
