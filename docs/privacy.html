1. 적용 범위

이 방침은 Xena Music 데스크톱 앱과 이 배포 웹사이트에 적용됩니다. Xena Music은 이용자가 보유한 음악 파일을 재생하고 보관함, 태그, 가사와 재생 설정을 관리하는 앱입니다. Google Drive 연결은 선택 사항이며, 연결하지 않아도 로컬 음악 재생과 편집 기능을 사용할 수 있습니다. 현재 배포 버전에서는 새 Google 계정 연결을 준비 중이며, 이미 연결한 PC는 기존 설정에 따라 동기화합니다.

Google, GitHub 및 아래에 설명한 선택적 검색·다운로드 제공자가 자체 서비스에서 처리하는 정보에는 각 서비스의 개인정보처리방침도 적용됩니다.

2. 처리하는 정보와 이용 목적

정보이용 목적 및 저장 위치
음악 파일, 파일 경로, 제목·가수·앨범·트랙·디스크·발매년도 등의 태그, 앨범아트, 가사음악 재생, 검색, 보관함 표시 및 편집에 사용하며 이용자 PC에 저장합니다. Drive 동기화를 사용하면 동기화 대상 음악 파일과 곡 정보도 이용자의 Google Drive에 저장합니다. 음악 파일에 포함된 태그와 이미지 등도 파일과 함께 전송됩니다.
좋아요, 플레이리스트, 감상 기록, 재생 대기열, 앱 설정이용자 PC에서 재생 기능과 개인 설정을 제공하는 데 사용합니다. Drive에는 곡별 좋아요와 동기화 가능한 앱 설정을 전송합니다. 현재 플레이리스트, 감상 기록, 재생 대기열 자체는 Drive 동기화 대상이 아닙니다.
앱에 등록한 아티스트 사진, 플레이리스트 이미지, 재생 화면 배경 사진보관함과 재생 화면 표시에 사용하며 이용자 PC에 저장합니다. Drive 동기화를 사용하면 아티스트 사진도 이용자의 Google Drive에 저장합니다. 플레이리스트 이미지와 배경 사진은 Drive 동기화 대상이 아닙니다.
Google 계정의 이메일 주소, 표시 이름, Drive 계정 식별자연결된 계정을 표시하고 계정별 동기화 데이터를 구분합니다. Drive API가 반환하는 계정 정보를 이용하며, Google 계정 비밀번호를 받거나 저장하지 않습니다.
OAuth 액세스 토큰·갱신 토큰승인된 Google Drive 접근과 로그인 유지에 사용합니다. 이용자 PC에 운영체제의 암호화 기능을 이용하여 저장하며 배포자 서버로 전송하지 않습니다.
파일 식별자·해시, 동기화 연결 정보, 변경·삭제 기록, 마지막 동기화 시각, 오류 정보파일 구분, 중복 방지, 변경 사항 반영, 충돌 처리 및 실패한 작업의 복구에 사용합니다. 동기화에 필요한 곡별 변경·삭제 기록은 Drive에 저장하며, 로컬 경로와 기기별 처리 상태는 이용자 PC에 저장합니다.
앱 버전, 운영체제·실행 환경, 보관함 통계, 오류 및 진단 기록오류 확인과 문제 해결에 사용하며 기본적으로 이용자 PC에 저장합니다. 진단 보고서는 이용자가 직접 내보낼 때 파일로 생성되고 자동으로 배포자에게 전송되지 않습니다. 내보내기에서 파일 경로 포함을 선택하면 해당 경로도 보고서에 포함됩니다.
이용자가 온라인 검색 창에서 확인·입력한 곡명·가수명·앨범명, 선택한 검색 결과의 앨범 식별자이용자가 온라인 가사·앨범아트 검색을 실행할 때 해당 검색 제공자에 필요한 검색어를 전송하고 결과를 받습니다. 실제 음악 파일, Google 인증 토큰이나 보관함 전체 목록을 검색 제공자에 전송하지 않습니다.

3. Google Drive 권한과 동기화

현재 배포 버전에서는 새 Google 계정 연결을 준비 중입니다. 이미 연결한 PC는 기존 설정에 따라 계속 동기화하며, 이 항의 내용은 그 동기화에 적용됩니다. 연결 기능을 다시 제공할 때 요청 권한이나 처리 방식이 달라지면 이 방침을 먼저 갱신합니다.

Xena Music이 요청하는 Google 권한은 https://www.googleapis.com/auth/drive.file입니다. 이 권한은 앱이 생성한 파일 또는 이용자가 앱에 허용한 파일에 대한 접근을 제공합니다. Xena Music은 자신의 동기화 폴더와 관련 파일을 관리하며, Google Drive 전체에 대한 접근 권한이나 Gmail·연락처 접근 권한을 요청하지 않습니다.

연결을 승인하고 동기화가 활성화되면 앱이 음악 파일, 앨범아트, 아티스트 사진, 곡별 태그·가사·좋아요, 지원되는 앱 설정을 이용자의 Google Drive로 업로드하고 다른 PC에서 가져옵니다. 테마, 앨범아트 형태, 파형, 가사 표시, 이퀄라이저 등 기기 간에 공유할 수 있는 설정이 대상이며, 로컬 폴더 경로, 출력 장치, 인증 정보, 기기별 운영체제 설정은 공유 설정에 포함하지 않습니다.

0.6.6부터는 현재 보관함에 등록된 곡을 기준으로 동기화합니다. 그보다 이전 버전에서는 지정한 업로드 폴더에 따라 대상이 달라질 수 있습니다. 0.6.7부터 새 음악은 파일 선택이나 음악 파일 드래그로 추가하며, 음악 폴더 등록·감시 기능은 사용하지 않습니다. 이전에 보관함에 등록한 곡은 유지됩니다.

보관함 삭제 동기화를 지원하는 버전에서는 곡 제거 기록을 다른 연결 기기에 전달합니다. 0.6.6은 보관함 항목과 삭제 기록을 반영하고 음악 파일은 유지합니다. 0.6.7부터는 삭제가 동기화된 곡의 불필요한 음악 사본도 휴지통으로 이동합니다. Drive의 음악 사본은 다른 유지 중인 곡이 사용하지 않는 경우에만 Drive 휴지통으로 이동합니다. PC에서는 Xena Music이 직접 내려받아 만든 것으로 확인되는 사본만 운영체제 휴지통으로 이동하며, 이용자가 직접 추가한 원본 음악 파일은 유지합니다.

이전에 내려받은 파일이라도 앱이 만든 사본임을 확인할 수 없으면 자동으로 삭제하지 않습니다. 예를 들어 0.6.6에서 이미 다운로드를 마친 파일은 다운로드 폴더에 있다는 이유만으로 삭제하지 않습니다. 이런 파일은 설정에서 실제 경로를 확인한 뒤 이용자가 직접 선택하여 휴지통으로 이동할 수 있습니다.

휴지통 이동은 영구 삭제와 다릅니다. 앨범아트, 곡 정보의 변경 기록과 삭제 기록은 삭제한 곡이 다시 등록되는 일을 방지하는 등의 동기화 처리를 위해 별도로 남을 수 있습니다. 이러한 기록에는 제목·가수·가사 등 기존 곡 정보가 포함될 수 있으며, 전체 데이터 삭제 방법은 아래 7항에 안내합니다.

전송은 이용자 PC와 Google 사이에서 이루어집니다. Xena Music 배포자가 별도의 서버에 음악 파일, 가사 또는 Google 인증 토큰을 수집하여 보관하는 구조는 사용하지 않습니다. 앱은 동기화 파일을 공개 공유로 전환하지 않으며, 이용자가 Google Drive에서 직접 설정한 공유 권한은 별도로 적용됩니다.

4. 정보의 이용 제한과 외부 제공

Xena Music은 Google API를 통해 받은 정보의 이용 및 다른 앱으로의 전송에 관하여 Google API Services User Data Policy의 제한적 이용(Limited Use) 요건을 따릅니다. 해당 정보는 이용자가 선택한 음악 재생·관리·동기화 기능을 제공하는 데 사용합니다.

Xena Music 배포자는 이 정보를 판매하거나 광고·광고 타기팅·신용 평가 목적으로 이용하지 않으며, 범용 AI 또는 머신러닝 모델의 생성·학습·개선에 사용하거나 제공하지 않습니다. 배포자는 이용자의 Drive 파일을 일반 운영 과정에서 열람하지 않습니다. 이용자가 문제 해결을 위해 특정 자료를 직접 제공하는 경우에는 해당 문의 처리에 필요한 범위에서 확인합니다.

동기화 시 Google은 저장 서비스 제공자로서 파일과 요청을 처리합니다. 앱 업데이트 확인·다운로드와 배포 웹사이트 이용 시 GitHub 및 배포 인프라가 네트워크 요청에 필요한 IP 주소와 요청 정보를 처리합니다. 업데이트 확인을 위해 이용자의 음악 파일이나 가사를 GitHub에 전송하지 않습니다.

선택적 온라인 가사·앨범아트 검색

온라인 검색 창에서 검색 버튼을 누르면 가사 검색에는 곡 제목과 입력된 가수명·앨범명을 LRCLIB에 전송합니다. 앨범아트 검색에는 앨범명과 입력된 가수명을 MusicBrainz에 전송합니다. 검색 창에서 검색할 항목(곡 제목·가수·앨범 등)을 직접 고르면 그 항목에 입력한 검색어를 같은 제공자에 전송합니다. 앨범 검색 결과의 그림과 선택한 앨범아트는 해당 앨범 식별자로 Cover Art Archive 및 그 이미지 제공 경로인 Internet Archive에서 내려받습니다.

이 요청에는 통신에 필요한 IP 주소와 Xena Music의 이름·버전을 포함한 요청 정보가 전달됩니다. 검색어는 현재 곡 정보로 채워질 수 있으며, Google Drive에서 가져온 곡의 정보도 이용자가 검색을 실행하면 같은 방식으로 전송됩니다. 검색 창에서 검색어를 확인·수정할 수 있고 검색을 실행하지 않을 수도 있습니다. 검색 제공자에게 음악 오디오, Google 인증 정보, 파일 경로 또는 기존 가사 본문을 업로드하지 않습니다. 받은 검색 결과는 이용자가 선택하여 곡 정보 편집에 적용합니다.

선택적 자동 가사 싱크

자동 가사 싱크의 음성 인식 도구를 설치할 때는 GitHub에서 whisper.cpp 실행 파일을, Hugging Face에서 음성 인식 모델을 내려받습니다. 다운로드 제공자와 해당 배포 인프라는 IP 주소와 파일 다운로드 요청 정보를 처리할 수 있습니다.

설치 후 음악 오디오의 음성 인식과 가사 시점 분석은 이용자 PC에서 실행됩니다. Google Drive에서 가져온 곡을 분석하는 경우에도 이 기능을 위해 오디오나 가사를 GitHub, Hugging Face 또는 외부 음성 인식 서버에 업로드하지 않습니다. 분석용 임시 오디오와 결과 파일은 로컬 작업 폴더에 만들고 작업이 완료되거나 취소되면 삭제를 수행합니다. 사용자가 적용·저장한 가사 싱크 정보는 곡의 가사 데이터로 보관되며, Drive 동기화가 활성화된 경우에는 다른 가사 정보와 함께 동기화됩니다.

5. 저장과 보호

Google API와의 외부 통신에는 HTTPS를 사용합니다. OAuth 인증 토큰은 운영체제의 보안 기능으로 암호화하여 PC에 저장하며, 안전한 암호화 저장소를 사용할 수 없으면 Google 연결을 진행하지 않습니다.

음악 파일, 보관함 데이터, 다운로드 파일과 내보낸 백업에 앱 자체의 일괄 암호화를 적용하는 것은 아닙니다. 이 데이터는 이용자 PC의 접근 권한과 Google Drive의 계정·공유 설정에 따라 보호됩니다. 인증 토큰과 일반 음악·설정 파일은 저장 방식이 다릅니다.

6. 보관 기간과 연결 해제

직접 추가한 원본 음악, 앱 설정과 백업은 이용자가 삭제할 때까지 해당 저장 위치에 남을 수 있습니다. 보관함의 곡 항목과 앱이 만든 다운로드 사본에는 위에서 설명한 0.6.7 이상의 삭제 동기화가 적용될 수 있습니다. 직접 추가한 원본 파일은 삭제 동기화 대상이 아닙니다. 로컬 진단 기록은 앱의 크기 제한에 따라 순환 보관됩니다.

Drive 음악 사본은 이용자가 직접 삭제하거나 삭제 동기화로 휴지통에 이동할 때까지 보관됩니다. 다른 곡이 사용하는 음악 사본과 앨범아트·곡 정보의 변경 기록·삭제 기록은 계속 보관될 수 있으며, 전체 삭제를 원하면 관련 파일을 직접 삭제해야 합니다. 휴지통 항목의 보관과 영구 삭제는 Google Drive 또는 해당 운영체제의 휴지통 정책과 이용자의 조작에 따릅니다.

앱에서 Google 연결을 해제하면 해당 PC의 동기화를 중지하고 저장된 인증 토큰을 제거하며 Google에 권한 취소를 요청합니다. 인터넷 연결 등의 문제로 Google 측 취소 요청이 완료되지 않을 수 있으므로, 권한을 확실히 해제하려면 아래 Google 계정 연결 관리 화면에서도 확인할 수 있습니다.

연결 해제는 이미 저장된 Drive 파일, 로컬 음악, 다운로드, 백업을 삭제하지 않습니다. 같은 계정의 중복 처리나 미완료 삭제 작업을 처리하기 위한 로컬 동기화 기록이 남을 수 있습니다. 앱 제거만으로 별도 데이터 폴더나 직접 내보낸 파일까지 모두 삭제된다고 간주해서는 안 됩니다.

7. 이용자의 선택과 삭제 방법

  • 자동 동기화 중지: 앱의 Google Drive 설정에서 자동 동기화를 끄거나 연결을 해제할 수 있습니다. 로컬 재생 기능은 계속 사용할 수 있습니다.
  • Google 접근 권한 취소: Google 계정의 서드 파티 연결 관리에서 Xena Music을 선택하고 연결을 삭제할 수 있습니다. 권한 취소만으로 Drive 파일이 삭제되지는 않습니다.
  • 곡 삭제 동기화: 연결된 보관함에서 곡을 제거하면 삭제 기록이 다른 연결 기기에 반영됩니다. 0.6.7 이상에서는 해당 곡에만 필요한 Drive 음악 사본과 앱이 직접 생성한 것으로 확인되는 로컬 다운로드 사본을 각 휴지통으로 이동합니다. 원래 보유한 음악 파일은 유지되며, 오프라인 기기에는 다시 연결되어 동기화할 때 반영됩니다.
  • 이전 다운로드 파일 정리: 자동 정리 대상인지 확인할 수 없는 기존 다운로드 파일은 설정의 정리 화면에서 경로를 확인하고 삭제할 파일을 직접 선택할 수 있습니다. 선택한 파일은 운영체제 휴지통으로 이동합니다. 폴더 위치나 이름만으로 기존 파일을 자동 삭제하지 않습니다.
  • Drive 데이터 삭제: 다시 업로드되지 않도록 연결된 모든 기기에서 동기화를 중지하고 연결을 해제한 뒤, Google Drive의 Xena Music 동기화 폴더와 관련 파일을 삭제합니다. 영구 삭제하려면 Drive 휴지통에서도 삭제합니다. 직접 복사하거나 다른 위치로 이동한 사본이 있다면 그 사본도 별도로 관리해야 합니다.
  • 로컬 데이터 삭제: 앱을 종료한 뒤 Xena Music의 사용자 데이터 폴더, 다운로드한 음악 파일, 직접 내보낸 백업과 진단 보고서를 필요한 범위에서 삭제할 수 있습니다. 원래 보유한 음악 파일은 보관함 제거와 별개이므로 파일 자체를 지우려면 해당 저장 위치에서 직접 삭제해야 합니다.
  • 열람·수정·이동: 앱에서 곡 정보와 가사를 확인·수정할 수 있으며, 음악 파일 및 내보내기 기능으로 만든 파일은 이용자가 직접 보관하고 이동할 수 있습니다.

Google과 GitHub가 보관하는 서비스 운영 기록의 삭제와 보관 기간은 각 서비스의 정책 및 계정 관리 기능에 따릅니다.

8. 웹사이트와 문의

이 웹사이트는 GitHub Pages로 제공됩니다. 이 사이트에 별도의 방문 분석 스크립트나 광고 추적 코드를 설치하지 않습니다. GitHub는 Pages 서비스의 보안을 위해 방문자의 IP 주소를 기록할 수 있습니다.

개인정보 및 데이터 처리 관련 문의는 Xena Music GitHub Issues로 접수할 수 있습니다. 운영 주체는 Xena Music 배포자(xena-music)입니다. GitHub Issues는 공개되므로 비밀번호, OAuth 토큰, 비공개 음악 파일이나 불필요한 개인정보를 게시하지 마세요. 문의에 직접 첨부한 내용은 GitHub에 저장되며, 배포자는 문제 확인과 응답을 위해 해당 내용을 처리합니다.
