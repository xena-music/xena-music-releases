서비스 약관

Xena Music의 기능, 외부 서비스 연결과 이용 조건을 안내합니다.

시행일: 2026년 10월 11일 · 배포자: Xena Music(xena-music)

1. 제공 기능

Xena Music은 사용자가 보유한 음악 파일을 재생하고 보관함·가사·곡 정보를 관리하는 Windows용 소프트웨어입니다. 선택적으로 사용자의 Google Drive를 통한 음악·설정 동기화를 제공하며, 현재 배포 버전에서는 새 계정 연결을 준비 중입니다. 음악 스트리밍 서비스나 음악 콘텐츠 판매 서비스는 제공하지 않습니다. 사용 가능한 기능과 변경 사항은 배포된 버전의 릴리스 안내를 따릅니다.

2. 음악 파일과 콘텐츠

사용자는 재생·편집·업로드할 권한이 있는 음악, 가사, 이미지와 기타 콘텐츠를 사용해야 합니다. Xena Music을 설치하거나 Google Drive를 연결하는 행위가 해당 콘텐츠의 저작권이나 이용 권한을 부여하지는 않습니다. 사용자가 선택한 파일과 편집 내용은 사용자 본인이 관리합니다.

3. Google Drive 동기화

현재 배포 버전에서는 새 Google 계정 연결을 준비 중이며, 이미 연결한 PC는 기존 설정에 따라 동기화합니다. Google Drive 동기화는 사용자가 계정을 연결하고 권한을 승인한 경우에 동작합니다. 인터넷 연결, Google 계정의 접근 권한과 Drive의 여유 용량이 필요하며 Google 서비스의 이용 조건과 제한을 함께 적용받습니다. 자동 동기화를 끄거나 계정 연결을 해제할 수 있습니다.

0.6.7부터는 보관함에서 곡을 제거하면 삭제 동기화에 따라 더 이상 사용하지 않는 Drive 음악 사본과 앱이 직접 만든 것으로 확인되는 로컬 다운로드 사본을 휴지통으로 이동합니다. 이용자가 직접 추가한 원본 파일은 유지됩니다. 계정 연결 해제만으로 파일이 삭제되지는 않습니다. 휴지통 이동과 영구 삭제의 차이, 보관되는 변경·삭제 기록 및 기존 다운로드 파일의 수동 정리 방법은 개인정보처리방침을 확인해 주세요. 주요 파일은 별도 사본으로 보관하는 것이 좋습니다.

4. 업데이트와 지원

앱은 GitHub 릴리스를 통해 배포됩니다. 사용자는 설정에서 업데이트를 확인하고 지원되는 설치형에서 자동 업데이트를 사용할 수 있습니다. 운영체제·파일 형식·외부 서비스의 변경에 따라 동작이나 지원 범위가 달라질 수 있으며 변경 사항은 릴리스 안내에 게시합니다.

오류 신고와 기능 문의는 GitHub Issues를 이용해 주세요. 게시물은 공개되므로 로그인 토큰, 계정 비밀번호와 비공개 음악 파일을 게시하지 마세요.

5. 개인정보와 외부 서비스

앱과 홈페이지에서 처리하는 데이터는 개인정보처리방침에 설명합니다. Google Drive 및 GitHub의 이용에는 각 제공자의 약관과 개인정보처리방침이 적용됩니다. 앱에 포함된 외부 소프트웨어의 고지는 배포본의 제3자 고지 문서에서 확인할 수 있습니다.

6. 문서 변경

기능과 운영 방식이 바뀌면 이 문서를 갱신하고 시행일을 표시합니다. 데이터 처리 방식이 바뀌는 경우 개인정보처리방침도 함께 갱신합니다.
