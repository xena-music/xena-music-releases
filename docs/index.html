XENA MUSIC제나 뮤직

FEATURES

재생부터 보관함 관리까지

01

음악 보관함

파일 선택이나 음악 파일 드래그로 곡을 추가하고 앨범, 아티스트, 노래, 좋아하는 곡으로 탐색합니다. 플레이리스트와 감상 기록을 관리할 수 있습니다.

02

싱크 가사

원문·발음·번역을 1~3줄로 표시합니다. 줄마다 시간을 넣는 싱크 편집과 PC 안에서 분석하는 AI 자동 싱크, LRC·TXT 가져오기를 지원합니다.

03

곡 정보 편집

제목, 가수, 앨범, 발매년도, 트랙·디스크 번호, 앨범아트와 가사를 편집해 음악 파일에 저장합니다. 온라인 가사·앨범아트 검색도 지원합니다.

04

화면과 오디오 설정

사각형·원형 앨범아트, 6가지 파형, 밝게·어둡게 테마와 컬러 테마, 사진 배경을 고릅니다. 10밴드 이퀄라이저와 단축키를 설정할 수 있습니다.

05

별도 재생 창

미니 플레이어와 데스크톱 가사 창을 사용합니다. 재생 대기열의 순서를 바꾸고 임의 재생·반복 재생을 조작할 수 있습니다.

06

백업과 업데이트

앱 데이터 백업·복구와 보관함 점검을 지원합니다. 설정에서 새 버전을 확인하고, Windows 설치형에서 자동 업데이트를 사용할 수 있습니다.

OPTIONAL GOOGLE DRIVE SYNC

같은 Google 계정으로
음악과 설정을 동기화합니다.

사용자가 연결을 선택하고 권한을 승인하면, 동기화 대상 음악과 앱 설정을 사용자의 Google Drive에 저장합니다. 다른 PC에서도 같은 계정으로 연결해 불러올 수 있습니다.

새 계정 연결은 지금 준비 중이며, 추후 업데이트에서 다시 사용할 수 있습니다. 이미 연결한 PC는 기존 설정대로 동기화합니다.

데이터 처리와 삭제 방법 확인 →
요청 권한drive.file

Xena Music이 만든 파일 또는 사용자가 앱에 허용한 파일에 접근합니다.

동기화 데이터

음악 파일, 곡 정보, 앨범아트, 아티스트 사진, 가사, 좋아요와 지원되는 앱 설정입니다.

사용자 선택

로컬 재생에는 Google 로그인이 필요하지 않습니다. 설정에서 자동 동기화를 끄거나 계정 연결을 해제할 수 있습니다.
